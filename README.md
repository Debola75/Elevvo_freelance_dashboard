# Studiofolk — Freelancer Dashboard

A responsive, multi-page admin dashboard for a fictional freelance designer, built with React.

## Features

- **Overview:** Project, earnings, and task summary cards; a monthly earnings chart; and recent activity.
- **Projects:** Mock client projects with status, deadline, value, progress, and working status filters.
- **Profile settings:** Editable personal details with save feedback, plus password placeholder fields.
- **Notifications:** A header dropdown showing the three most recent mock activities.
- **Responsive layout:** Shared sidebar and header with mobile navigation.
- **Client-side routing:** Navigate between pages without refreshing.

## Tech stack

- React 18
- Vite
- React Router
- Recharts
- Lucide React

## Getting started

Requires Node.js and npm.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite to view the dashboard.

## Production build

```bash
npm run build
npm run preview
```
